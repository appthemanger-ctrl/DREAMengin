# Dynamic Dream Fusion (Next.js 16.1.4)

This project has been fully converted from a Vite + React app to a **Next.js 16.1.4** App Router project.

## 🔧 Tech Stack
- Next.js 16.1.4 (App Router)
- React 18.3
- Tailwind CSS 3.4
- TypeScript
- Drizzle ORM
- Supabase
- Passport (for optional auth)
- Zod

## 🗂️ Project Structure

```
app/              → App router pages and layout
styles/           → Tailwind CSS and globals
public/           → Static assets
docs/             → You're here
```

## 🚀 Getting Started

```bash
npm install
npm run dev   # Starts the Next.js app
```
