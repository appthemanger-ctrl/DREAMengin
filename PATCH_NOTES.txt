NEXT 14.x UPGRADE (not 15) — PATCH NOTES

What this does
--------------
• Bumps Next.js from 14.2.6 to latest 14.x (using "next": "^14.2.0").
• Adds TypeScript + Tailwind devDependencies (safe to add even if unused).
• Includes fallback tailwind.config.js and postcss.config.js (only copy if missing).

How to apply (Working Copy on iOS or Git)
-----------------------------------------
1) Replace your root package.json with the one in this patch.
2) Delete your lock file so Vercel picks new 14.x:
     • package-lock.json  (for npm)
     • yarn.lock          (if using yarn)
     • pnpm-lock.yaml     (if using pnpm)
3) (Optional) If you use Tailwind and the two config files are missing,
   copy tailwind.config.js and postcss.config.js to your repo root.
4) Commit and push.
5) Trigger a new Vercel deploy.

Notes
-----
• Using ^14.2.0 guarantees you stay on the 14 major (never upgrades to 15).
• If Vercel still builds 14.2.6, it means the lockfile was not replaced.
  Delete the lockfile and push again so the resolver fetches the newest 14.x.
