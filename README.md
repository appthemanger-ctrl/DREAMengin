### 🧑‍🚀 humanAI: Automated Product Audits & Persona Customization

DREAMengin ships with a unique **humanAI** audit system—**and you can fully customize its "personality"!**

- **What it is:** An automated "user" agent that explores your app like a real iPhone Safari user—no test scripts, no hardcoding. It crawls every page, discovers all code/API surfaces, and then writes a report *as if it were a real user with deep product knowledge*.
- **Persona customization:** Edit `agents/humanAI.persona.md` to instruct humanAI to behave like any user—power user, designer, complete beginner, accessibility advocate, etc. You can run audits from any perspective you want by simply changing the persona file before your CI run!
- **What it does:** Runs weekly (or on-demand) via CI, opening GitHub issues or adding artifacts with:
  - Human-readable, first-person feedback on UX, polish, clarity, and pain points
  - Real URLs, code paths, and specific actionable fixes
  - No generic bot-speak—only useful, opinionated commentary, never boilerplate
- **Why it matters:** For solo builders or non-coders it's like having a relentless, candid, product-savvy reviewer who checks your work every week—and you always get the perspective you actually need at the time.
- **Powered by:** `.github/scripts/humanai_audit.py` and persona spec in `agents/humanAI.persona.md` (see workflow: `.github/workflows/humanai-audit.yml`)

**Catch breakage, UX drift, or architectural issues long before users do—with zero code, and in any "voice" you choose!**
