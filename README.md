# DREAMengin (JS)

- Next.js 14 (App Router), JavaScript-only
- Tailwind + animated gradient
- Supabase helpers (optional; app still works in guest mode)
- Landing (`/`) → Login (`/login`) → Home (`/home`)
- Widgets via generated registry (promo, messages)
- Dr. Eam stub at `/api/assistant`

## Environment
Create `.env.local` at repo root (optional for guest mode):
```
NEXT_PUBLIC_SUPABASE_URL=your-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon
SUPABASE_SERVICE_ROLE_KEY=optional-for-admin
DR_EAM_MODE=local
```
Deploy on Vercel after adding the two NEXT_PUBLIC_... vars in Project → Settings → Environment Variables.

## Scripts
- `prebuild`: runs `scripts/prepare.mjs` to (a) generate module registry, (b) ensure dynamic pages are marked

## Folders
- `app/` routes
- `lib/` helpers
- `modules/widgets/*` widget modules
- `modules/registry.generated.js` auto-generated by prepare script
