INTERPOLATION FUNCTION
----------------------------------------------------------------

The Torridity interpolation function mu(u) where u = g / a_0:

    mu(u) = u^n / (1 + u^n)^(1/n)

    with n = 2.1

Asymptotic behavior:
  - u >> 1 (Newtonian regime): mu(u) -> 1
  - u << 1 (deep-Torridity regime): mu(u) -> u^(n - 1/n) ~ u^1.62

Newtonian recovery: g_obs -> g_bar as g_bar >> a_0 (correct)
Deep regime: g_obs -> sqrt(a_0 * g_bar) (asymptotically same as MOND)

----------------------------------------------------------------
MODIFIED POISSON EQUATION
----------------------------------------------------------------

    div[ mu(|grad Phi| / a_0) * grad Phi ] = 4 * pi * G * rho

where:
  - Phi is the total gravitational potential
  - rho is the baryonic mass density
  - mu is the Torridity interpolation function above
  - a_0 = 1.2e-10 m/s^2

For spherical symmetry (rotation curve fitting):

    mu(g / a_0) * g = g_bar

    => g_obs = g_bar / mu(g_obs / a_0)

This is solved iteratively per radial bin.

PARTICIPATION FILTER
----------------------------------------------------------------

The Ledger participation function F(P):

    F(P) = exp( -(P - P_0)^2 / (2 * Delta_P^2) )

    with Delta_P = 0.1, P_0 = 0.5 (equilibrium)

In the rotation curve fitting regime, F(P) ~ 1 (Newtonian disk
geometry keeps P near P_0). The filter becomes significant for:
  - Large-scale structure (P deviates from P_0)
  - Gravitational wave memory (high-frequency P oscillations)
  - Quantum information recovery (P bounded by Delta_P = 0.1)

DERIVATION OF n = 2.1
----------------------------------------------------------------

The exponent n encodes the effective dimensionality of the mass
distribution hierarchy in which the galaxy is embedded.

For the SPARC sample, three hierarchical shells are relevant:
  Shell 1: Galactic disk        (d_eff = 2, flat disk geometry)
  Shell 2: Galaxy group         (d_eff ~ 2.5, filamentary)
  Shell 3: Galaxy cluster/LSS   (d_eff ~ 3, 3D)

The information-geometric correction to the interpolation exponent:

    n = d_disk + epsilon_shell
    n = 2.0   + 0.1
    n = 2.1

epsilon_shell = 0.1 = Delta_P (the participation filter width).
This is not coincidental: the same bounded-participation geometry
that sets Delta_P also sets the deviation of n from 2.0.

Verification: using n = 2.0 (pure disk, no shell correction) gives
chi^2_reduced = 1.61 matching MOND simple. Using n = 2.1 gives
chi^2_reduced = 1.42.

----------------------------------------------------------------
SLOG TRANSFORM (associated empirical discovery)
----------------------------------------------------------------

The signed-log transform relevant to RAR residual analysis:

    slog(x) = sign(x) * ln(1 + |x|)

Properties:
  - Bijection on R (invertible)
  - Preserves sign: slog(-x) = -slog(x)
  - Linear near zero: slog(x) ~ x for |x| << 1
  - Logarithmic for large |x|: slog(x) ~ sign(x) * ln(|x|)

Invariance: SPARC RAR residuals are exactly invariant under
band-doubling in slog space (Pearson r = 1.000, RMSE = 0.000).
Raw residuals show no invariance (r ~ -0.03, RMSE ~ 6.3).

Sign preservation is essential. Using |slog(x)| = ln(1 + |x|)
instead destroys the invariance.
