# CCC / ADA Twin-Engine Research Archive

*Jose Mancilla — DREAMengin Research — May 2026*

This directory is the archive landing place for the CCC / ADA Twin-Engine research bundle. It keeps the new papers, data artifacts, decoder materials, and sharpening notes together under `research/` so the work is discoverable from the main research index without mixing it into product runtime code.

## Scope

The CCC / ADA Twin-Engine program treats conserved causal compression (CCC) and adaptive decoherence accounting (ADA) as coupled engines:

1. **CCC** tracks what remains invariant as a system compresses state across scales.
2. **ADA** tracks what participation limits, boundary losses, and recovery ceilings are introduced as the compressed state is observed or reconstructed.
3. The **Twin-Engine** coupling asserts that physical predictions emerge only when conservation and accounting are evaluated together.

This archive is organized as a research record, not as an application feature. It can contain manuscripts, notes, raw or derived tables, digitized plot data, and reproducibility code.
