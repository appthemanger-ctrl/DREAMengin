# CCC / ADA Twin-Engine Data Artifacts

This directory is reserved for raw and derived data files that support the CCC / ADA Twin-Engine papers.

| File | Description | Related paper |
|------|-------------|---------------|
| `torr_vs_mond_lock_n1567.csv` | Extended Torridity vs MOND rotation-curve comparison table | `paper/ccc_ada_predictions_and_falsifiability.tex` |

## Data documentation rule

When each source artifact is added, document its columns or fields here before using it for claims in the papers. CSV files should keep their original column names intact so the archive remains traceable to the owner-supplied source.
