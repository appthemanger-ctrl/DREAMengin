\begin{abstract}
We specialize CCC / ADA to black-hole information recovery and gravitational-wave memory. The core proposal is that memory is the observable trace of conserved compression crossing an accounting boundary. Black-hole horizons, merger remnants, and gravitational-wave memory signals are treated as boundary systems whose recoverable information is constrained by a finite participation deficit.
\end{abstract}

\section{Boundary Compression}
A black-hole horizon compresses exterior causal history into boundary-accessible observables. In CCC language, the horizon is a compression surface. In ADA language, it is also an accounting surface: not every compressed degree of freedom can be recovered with unit fidelity.

\section{Recovery Ceiling}
Let $\Delta P_A$ be the accounting deficit associated with horizon participation. The maximum operational recovery fidelity is
\begin{equation}
F_{\max} = 1 - \Delta P_A.
\end{equation}
This expression should be read as a falsifiable ceiling, not a metaphor. A system that reliably exceeds the ceiling is evidence against the proposed accounting rule.

\section{Gravitational-Wave Memory}
Gravitational-wave memory is the persistent displacement left after radiation has passed. In the Twin-Engine view, it is an ADA-visible remainder of a CCC event: a merger compresses causal structure, and the memory term records what accounting could not erase.

\section{Connection to Slog Residuals}
The existing Torridity record predicts a correlation between gravitational-wave memory amplitude and local signed-log residual structure. CCC / ADA gives that prediction a broader interpretation: the host environment supplies a signed compression coordinate, while the wave memory supplies the boundary accounting trace.

\section{Falsification}
The specialization is falsified if gravitational-wave memory amplitudes show no statistically meaningful relationship to the signed residual coordinate after host-environment controls are applied, or if recovery systems exceed the predicted participation ceiling without a compensating accounting term.
