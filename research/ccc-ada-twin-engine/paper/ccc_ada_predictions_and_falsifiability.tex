\begin{abstract}
A research archive is useful only if its claims can fail. This manuscript states falsifiability gates for the CCC / ADA Twin-Engine program. The tests are organized by domain: galaxy residuals, gravitational-wave memory, black-hole recovery, holographic boundary behavior, and decoder benchmarks.
\end{abstract}

\section{Gate 1: Signed Residual Invariance}
Prediction: residual structures tied to conserved compression should become more stable under sign-preserving transforms than under unsigned transforms. Falsification: unsigned transforms match or outperform signed transforms across the target datasets after controls.

\section{Gate 2: Memory Correlation}
Prediction: gravitational-wave memory should correlate with the local signed residual coordinate of the host environment above a declared threshold. Falsification: the correlation fails under combined high-quality observations, or disappears when obvious covariates are controlled.

\section{Gate 3: Recovery Ceiling}
Prediction: systems that instantiate the ADA accounting boundary should show a finite recovery ceiling. Falsification: recovery fidelity exceeds the proposed ceiling reproducibly without an additional accounting term.

\section{Gate 4: Boundary Deficit Conservation}
Prediction: information not recoverable at the boundary should reappear as entropy, latency, residual memory, or another measurable deficit. Falsification: no conserved deficit can be found when the full accounting budget is closed.

\section{Gate 5: Decoder Benchmark Consistency}
Prediction: GF(256) decoder benchmarks should show stable timing or failure modes that track the same participation budget used in the theoretical papers. Falsification: benchmark structure is random with respect to the proposed accounting variables.

\section{Archival Rule}
Each future dataset added to this bundle should identify which falsifiability gate it addresses, what result would count against the framework, and which file records the measurement.
