# Principle: Mastery

## Definition
The skill ceiling must remain visibly above the player's current ability for
the entire intended playtime, while the skill floor stays accessible enough
that an entry-level player can complete the core loop.

## Indicators
- Speed-run viability of every level.
- Optional skill challenges (e.g. "no-hit" runs) tracked in telemetry.
- Visible "depth markers": leaderboards, hidden routes, advanced tech.

## Anti-Patterns
- Skill floor too high → mass quit at level 1–3.
- Skill ceiling too low → boredom by level 10.
- Ceiling reachable only via speedrun-only knowledge with no in-game discovery path.
