# Principle: Emotional Core

## Definition
Every cartridge must declare a single primary emotion it intends to evoke and
align all subsystems (mechanics, art, narrative, audio) toward sustaining it.

## Catalog
| Core | Cartridge Examples | Mechanical Levers |
|------|--------------------|-------------------|
| Empowerment | _Madmaxi_, _Hollow Knight_ | Rising power curve, optional bosses |
| Catharsis   | _Celeste_                  | Personal-struggle narrative + difficulty |
| Wonder      | _Outer Wilds_              | Discovery beats, unmarked exploration |
| Tension     | _Dead Cells_               | Permadeath stakes, escalating threat |
| Calm        | _A Short Hike_             | Soft fail-states, ambient music |

## Anti-Patterns
- Tonal whiplash between zones with no narrative justification.
- Mechanical reward loops that contradict declared emotion.
